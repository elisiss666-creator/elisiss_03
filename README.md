# 天秤之城：平行時空

給國小六年級使用的純 Web 情境思辨遊戲。主題為「法律與道德如何一起保護生活」，支援 PC 與 iPad，不需要建置工具、套件或資料庫，可直接部署到 GitHub Pages。

## 開啟與部署

- 遊戲入口：`dist/index.html`
- 本機預覽：在專案目錄執行 `python -m http.server 8765 --directory dist`
- GitHub Pages：將 `dist/` 內的檔案發布為靜態網站即可；`dist/.nojekyll` 已保留。

## 遊戲內容

1. 起點教學：PC 方向鍵／WASD、E／空白鍵；iPad 虛擬搖桿與互動按鈕。
2. 世界一「只看規定城」：遺失物、主動助人、拾得物報酬程序。
3. 世界二「只靠勸說森林」：傳言、證據、公平調查與關係修復。
4. 世界三「規則與善意合作島」：透明交接、安定情緒、共同約定。
5. 終章「天秤議會」：將八種行動判斷為規則要求、善意選擇、兩者都有或資料不足。
6. 結果頁「我的思辨旅程」：呈現規則守護、關懷溫度與下一步挑戰，不做學生排名。

每個選擇都會立即呈現後果與思考提示。不理想的選擇不會造成永久失敗，後續仍可透過查證、更正、道歉或建立程序來修復。進度使用瀏覽器 `localStorage` 自動保存。

## 教學用語與法律內容

- 遺失物先交還失主，或送交警察／適當的管理單位處理。
- 拾得人的報酬請求有條件與程序，最高可到物品價值十分之一；不是看到 2,000 元就能直接拿走 200 元。
- 自行留下遺失物可能涉及「侵占遺失物」，遊戲不將它誤稱為一般竊盜。
- 所有內容採六年級可理解的短句，並區分「猜測」、「可核對的事實」與「資料不足」。

## 驗證

- `node --check dist/game.js`
- `node qa/map-reachability.cjs`
- `node qa/qa.cjs`

`qa/qa.cjs` 會從標題一路自動通關到結局，檢查圖片載入、瀏覽器錯誤、PC 橫向溢位及 iPad 觸控按鈕尺寸，並將畫面存至 `qa/output-v3/`。
